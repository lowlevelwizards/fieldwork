# Fieldwork AI 3.1A–B — Behavioral Truth & Concurrent Concerns

## Delivered

- Added long-running behavioral truth instrumentation for pacing, overlap, static threat exposure, close-contact nonreaction, static fights, casualty attendance, and concern changes.
- Added 20-second deterministic behavior fixtures that exercise casualty recovery and live mission/contact concurrency.
- Added `npm run behavior:report` and complete JSON reporting for repeatable before/after comparison during the unified-brain migration.
- Added a non-authoritative `TeamConcernBoard` that keeps mission, contact, casualty, and safe-return obligations alive simultaneously.
- Added direct physical casualty projection so a present incapacitated teammate cannot disappear merely because another encounter wins the legacy response slot.
- Added direct incoming-fire projection so immediate hostile pressure appears on the board before it necessarily becomes the best shared encounter hypothesis.
- Added concern lifecycle, stable IDs, evidence, desired effects, staffing needs, legacy projection, diagnostics, and decision-log events.

## Intentionally unchanged

The legacy agenda, response, procedure, role-position, tactical-deliberation, arbiter, scheduler, and physical action paths remain authoritative. This build measures them and mirrors their pressures; it does not yet replace them.

## Next migration boundary

AI 3.1C should introduce the unified actor brain as the only producer of coherent behavior plans, initially wrapping existing atomic actions while comparing continuation utility against concrete candidate plans.
