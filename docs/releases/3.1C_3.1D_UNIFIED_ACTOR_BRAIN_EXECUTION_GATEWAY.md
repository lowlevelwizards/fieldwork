# AI 3.1C–D — Unified Actor Brain & Single Execution Gateway

## Purpose

3.1C–D replaces the fragmented physical-control topology with one actor-level proposal gateway while retaining the existing perception, team concern, procedure, action, and executor systems during migration.

The governing rule is now:

```text
many evidence and intent producers
→ one unified actor brain
→ one authority arbiter
→ one action scheduler
→ physical executors
```

No role, travel, defensive, contact, initiative, autonomy, or tactical runtime may start an action directly.

## Unified actor brain

`UnifiedActorBrain` collects concrete action candidates for each actor during one simulation frame. It:

- compares authority, urgency, and utility;
- compares cross-type candidates against the continuation utility of active conflicting actions;
- applies a switch margin to prevent low-value churn;
- permits compatible channel intentions to coexist in one actor plan;
- forwards accepted candidates to the existing authority arbiter;
- records rejected candidates, incumbent replacements, active plan actions, and available concurrent team concerns;
- centralizes action cancellation requests.

This is a migration bridge, not a second scheduler. The action scheduler remains the physical lifecycle owner, and the action arbiter remains the only module that calls `scheduler.start()`.

## Direct-writer migration

The following systems now publish candidates through the unified brain:

- actor initiative;
- tactical deliberation;
- contact resolution;
- operational travel;
- role actions;
- role-position movement;
- defensive-position movement and holding;
- local autonomy;
- authored observation and runtime-generated contact/casualty reports.

Cross-type replacement now uses one continuation comparison rather than relying only on scheduler priority side effects.

## Plan continuity safeguards

The migration exposed several hidden control leaks. This build also:

- preserves staged silent withdrawal authority until its physical plan reaches completion or reassessment;
- records completed withdrawal even when a contact track becomes stale during the last movement stage;
- releases destination, patient, drag, and cover-slot claims when unified-brain replanning interrupts an action;
- prevents critical casualties from receiving generic ready or anti-congestion movement behavior;
- prevents generic local redistribution from overriding active procedure roles, authored observation, unresolved threat tracking, or defensive-position responsibility.

## Validation contract

Static regression tests assert that:

- the action arbiter is the only AI V2 module that starts scheduler actions;
- actor behavior runtimes request cancellation through the unified actor brain.

Behavioral tests assert that:

- a higher-value cross-type plan can replace an incumbent;
- a lower-value challenger cannot create churn;
- compatible movement and attention intentions can coexist;
- casualty carrier handoff, warning, staged withdrawal, and defensive-position fixtures remain intact.
